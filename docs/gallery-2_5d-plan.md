# AI Timeline 展厅 · 开发计划（轴侧 2.5D）

> 方向已改：默认不做第一人称走廊。主路径是轴侧 2.5D 时间轴 + 拖拽/scrub + 红点；WASD 最多当彩蛋。全量检索仍留在 2D Tab。

相关：

- 线上展厅：https://shalom-lab.github.io/ai-timeline/#/gallery
- 仓库：https://github.com/shalom-lab/ai-timeline

## 总判

上一版「半改」仍把滑轨相机挂在走廊壳上，主路径没说死。已明确：**拖时间轴 + 红点比 WASD 方便**；**轴侧 2.5D** 比第一人称更贴「看时间线」。本计划按此作为默认方向。

数据现实：约 165 条、26 家公司；大模型远多于科学。等距三条跑道会让时空城感与密度说谎——轴侧视图必须用**真实日期**当唯一坐标，疏密可见。

## 用户已拍板的主交互

| 项 | 约定 |
| --- | --- |
| 视图 | 轴侧 2.5D（斜俯视/等距一类）：时间轴横贯画面，事件立在轴旁或轴上 |
| 主路径 | 拖拽 / scrub 时间轴；拖到哪看到哪；不靠走路翻页 |
| 事件 | 红点（或可点标记）落在轴上；点红点再展开详情 |
| WASD | 最多可选彩蛋；不得挡主路径，不得作为默认入口 |
| 2D | 列表 Tab 保留；同一份 `timeline.json`；3D 挂了或晕 3D 也能扫 |

## 现状硬伤（仍成立）

| 硬伤 | 对用户的伤害 | 本版怎么消 |
| --- | --- | --- |
| 走路才能翻页 | 吞吐差于 2D | 拖轴 / scrub 为主 |
| 年标与板两套坐标 | 时间说谎 | 唯一日期映射函数 |
| 年份疏密被熨平 | 爆发密度丢失 | 位置按真实日期，远景可簇 |
| Pointer Lock | 非玩家流失 | 默认不 Lock |
| 无搜索/过滤 | 找不着 | P2 回笼，命中高亮红点 |
| 手机摇杆主路径 | Pages 手机难用 | 触控拖轴 + 点红点 |
| 详情打断漫游 | 两头不靠 | 侧栏/贴板，关详情不重置相机 |

## 目标体验

1. 打开展厅：默认停在「最近一周」或最新一条附近；URL 可带日期 hash，分享直达。
2. 横向拖轴或滚轮/触控板 scrub；双指或滚轮缩放改变时间跨度（看十年 vs 看一个月）。
3. 轴上红点 = 事件；密时按年/月聚合成簇，拖近或放大再拆开；悬停高亮当前段。
4. 点红点 → 侧栏或贴板详情（标题/日期/链接）；←→ 或点邻近点跳下一条。
5. 轴旁可有浅 2.5D 展板/标签作氛围，但信息以红点 + 详情为准，不靠读糊贴纸。

**成功标准（验收）**：从进展厅到打开指定事件 ≤3 次明确操作；某年密度一眼可辨；手机可完成「滑到某年 → 点开一条」。验收用例含找 Hy4 / GPT 等节点。两周不过则收缩成英雄展，不继续打磨走路。

## 分阶段计划

### P0 · 停损与度量

定成功标准与 5 条验收用例写入 docs；去掉双顶栏/原型黄标对「可认真用」的暗示；本阶段仍不堆美术。

### P1 · 轴侧壳 + 唯一时间坐标

换掉默认第一人称走廊：轴侧相机；板位/红点位置 = 真实日期映射；年标与红点同一函数；疏密可见。

### P2 · 拖轴 / scrub + 红点

主路径：拖拽、滚轮、触控 scrub；红点可点；簇合与拆开；←→ 邻近跳转。WASD/漫游若保留，藏进可选开关。

### P3 · 找信息回笼

搜索与分类 chip；命中高亮并 scrub 到该红点；入口默认最近窗口；URL hash 同步当前日期/事件。

### P4 · 详情与可读性

侧栏/贴板详情；近距才抬纹理或用 HTML overlay；关详情不重置视角。

### P5 · 密度与性能

视距 LOD、远景年份广告牌、簇合；视差层浅景深可选；165 全量可留，远景禁止同等黑板墙。

### 闸门 · 两周后

验收不过 → 收缩「年度英雄展 / 精选里程碑」；通过 → 再谈灯光与微动效。

## 还可抠的优化

- **密度簇**：多点重叠时先簇后拆，避免红点糊成一片。
- **视差层**：拖轴时前景细动、背景慢移，增强 2.5D，不做满屏 FPS。
- **触控与键鼠**：滚轮横向 scrub、双指缩时间跨度；←→ 跳邻近红点。
- **入口与分享**：默认最近一周；URL 日期/事件 hash。
- **无障碍**：2D 列表永远可用；3D 失败时降级提示，不白屏。

## 自批

1. **上一版默认「半改滑轨」仍绑着走廊隐喻**  
   - 问题：容易继续打磨走路手感，主路径说不清。  
   - 改正：主路径写成拖轴 + 红点；轴侧 2.5D 是默认壳。

2. **案例参考偏博物馆 scrub，与原意不完全贴近**  
   - 问题：用别人展馆范本硬套「跨栏跑道」。  
   - 改正：保留「空间里看时间」的感觉，但交互跟拖轴/红点，不跟别人的走路导览。

3. **仍可能偏乐观**  
   - 轴侧若做成「带透视的普通时间轴」，可能被问为什么不回 2D——闸门必须真砍。  
   - 黑板隐喻是否保留未拍板；先定交互，再定皮。

## 明确不做

- 未确认本计划前继续堆 FPS、碰撞、跨栏装饰
- 默认 Pointer Lock / WASD 当主入口
- 为 165 条各做一张高清独立艺术展板
- 拆掉 2D 列表、强迫只走 3D
- 用无关能力（云端出图等）「丰富」展厅
